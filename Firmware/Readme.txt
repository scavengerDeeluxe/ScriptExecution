This folder contains AVR Firmware for FlashcatUSB Classic and XPORT.
NOTE: NOT FOR PCB 3.x (Professional). The Pro software automatically updates the firmware and contains all needed features.
Loading these firmwares will change the base functionality of FlashcatUSB.
For instructions on how to change firmware, please read the enclosed Documentation.
-----------------------------------------------
FCUSB.CLASSIC.x.xx.SPI: Allows programming of high-density SPI flash devices, and Extension I/O (NOR, NAND)
FCUSB.CLASSIC.x.xx.EJTAG: Allows programming of CFI devices over JTAG using DMA or PrAcc mode.
FCUSB.XPORT.x.xx.EXT: Allows programming of parallel NOR memory and SLC NAND devices for XPORT hardware version.
-----------------------------------------------
Please note, PCB 1.x has been discontinued and is no longer supported. Please consider upgrading to PCB 2.x or 3.x.
